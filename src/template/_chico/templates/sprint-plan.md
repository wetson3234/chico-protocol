## 6. Definition of Done (DoD)

Each user story is considered "Done" when:

- [ ] The code is written and follows project conventions
- [ ] TypeScript types are complete (no `any`)
- [ ] Unit tests are written and pass (coverage > [X]%)
- [ ] Integration tests pass
- [ ] The code has been reviewed by at least 1 other developer
- [ ] The PR is merged into the target branch
- [ ] The feature is deployed to staging
- [ ] The feature has been manually tested in staging
- [ ] Documentation is up to date (if applicable)
- [ ] All user story acceptance criteria are validated
- [ ] No regressions on existing tests
